# Lean CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore low-cost automated pull-request verification without running Playwright on every update.

**Architecture:** Add one GitHub Actions workflow with a single default Lean CI job that runs the repository's existing `pnpm check` command. Keep browser verification in a second conditional job activated by the `full-ci` label or manual dispatch, with workflow concurrency cancelling obsolete runs.

**Tech Stack:** GitHub Actions, Node.js 22, pnpm 10.13.1, Playwright Chromium, existing repository scripts.

## Global Constraints

- Keep `petechatchawan/web-three-city` private.
- Do not restore automated Vercel deployment.
- Do not modify application or package behavior.
- Use `ubuntu-latest`, Node.js `22`, and pnpm `10.13.1`.
- Default pull-request verification must use one runner job.
- Playwright must not run on every pull-request update.
- Documentation-only pull requests must not trigger automatic CI.

### Task 2: Add the Lean CI workflow

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: root `package.json` scripts `check`, `build`, and `test:browser`.
- Produces: `Lean CI` and conditional `Full browser verification` GitHub status checks.

- [ ] **Step 1: Create the workflow**

```yaml
name: CI

on:
  pull_request:
    types: [opened, synchronize, reopened, labeled]
    paths-ignore:
      - 'docs/**'
      - '**/*.md'
  workflow_dispatch:

permissions:
  contents: read

concurrency:
  group: ci-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  lean:
    name: Lean CI
    if: github.event_name == 'workflow_dispatch' || github.event.action != 'labeled'
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 10.13.1
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm check

  browser:
    name: Full browser verification
    if: >-
      github.event_name == 'workflow_dispatch' ||
      (github.event_name == 'pull_request' &&
      contains(github.event.pull_request.labels.*.name, 'full-ci'))
    runs-on: ubuntu-latest
    timeout-minutes: 25
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
        with:
          version: 10.13.1
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm --filter @web-three-city/terrain-lab build
      - run: pnpm --filter @web-three-city/game build
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:browser
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: browser-evidence
          path: |
            playwright-report
            test-results
          if-no-files-found: ignore
```

- [ ] **Step 2: Review the workflow contract**

Confirm all of the following directly from the committed file:

- `Full browser verification` is conditional.
- `paths-ignore` covers `docs/**` and `**/*.md`.
- Concurrency cancellation is enabled.
- Permissions are read-only.
- No deployment step exists.
